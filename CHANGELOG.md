# THE NEXT INFECTION — Changelog

## Module 010 — Combat & Immersion (2026-11-14)

- Three permanent weapon slots across open-world and survival scenes.
- Per-slot magazine/reserve ammo state during the active scene.
- Gunsmith crafting, saved loadouts, and permanent weapon upgrades.
- ADS, improved original weapon viewmodels, muzzle flash, recoil and reload motion.
- Mystery Box preview with user-selected replacement slot.
- Walker, Runner and Brute zombie profiles, approximate headshots, attack windup, flinch and death reactions.
- Orlando safehouse armory shortcut; asphalt/concrete material improvements.
- Preserves cumulative Module 009 systems: Florida district travel, driving, missions, salvage persistence, local plot building and match banking.

### Known limitations
- Still procedural/low-poly visuals rather than photorealistic assets.
- Local single-device ownership and save records; no authoritative server or multiplayer.
- No exported Android APK; import source in Godot.
- Engine CI and more complete Android gameplay/regression tests are required before merging.
