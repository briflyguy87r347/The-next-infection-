## Module 002 — First-Person Player Controller

The current prototype includes a first-person player with walking, sprinting,
jumping, gravity, and smoothed mouse/touch camera look. On desktop, use **WASD**
to move, **Shift** to sprint, **Space** to jump, and the mouse to look (click to
recapture the cursor; **Esc** releases it). Android devices display a movement
joystick, look-drag area, jump button, and sprint button.

The player spawns on a collidable ground surface with a few block obstacles.
The project uses the GL Compatibility renderer and a 960 × 540 3D viewport for
the entry-level tablet target. Touch layout, performance, and input feel still
need testing on physical Android devices.
